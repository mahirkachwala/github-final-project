# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Fork this repository and create a branch for your change.
2. Make your changes and test the calculator with representative input values.
3. Commit your changes with a clear message.
4. Open a pull request describing what changed and how you tested it.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) when participating in this project.
