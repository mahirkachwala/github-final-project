# Simple Interest Calculator

This project provides a Bash script that calculates simple interest from values entered by the user.

## Inputs

- Principal amount (P)
- Annual rate of interest as a percentage (R)
- Time period in years (T)

## Formula

Simple interest = (P × R × T) / 100

The script displays the simple interest and the total amount (principal plus interest).

## Run

```bash
bash simple-interest.sh
```

Enter the principal, annual interest rate, and time period when prompted. For example, a principal of 1000 at 5% per year for 2 years yields simple interest of 100 and a total amount of 1100.
